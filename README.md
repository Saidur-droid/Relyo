# Relyo

> **AI builds it. Relyo makes sure reality agrees.**

Relyo is an autonomous production control plane for AI-built software. It discovers how an application actually works across code, infrastructure, identity, data, payments, communications, domains, third-party APIs, cost, recovery, and real user journeys; fixes launch blockers with approval-gated automation; independently verifies outcomes in production; and continuously proves the software remains safe, recoverable, cost-aware, and operational.

## The category

AI has made software creation dramatically easier. Production trust is now the bottleneck.

Relyo is not another code generator, repository scanner, hosting platform, monitoring dashboard, or generic desktop agent. It is the independent control and verification layer between machine-generated software and the real world.

## Core promise

**Connect your AI-built app → Relyo discovers the production system → repairs what is safe to repair → asks for approval where required → deploys and verifies real customer journeys → keeps proving the business works.**

## Initial wedge

The first production-grade release focuses on the most common AI-app stack:

- GitHub
- Vercel
- Supabase
- Google OAuth / GitHub OAuth
- Stripe
- Resend
- Cloudflare

The architecture remains provider-neutral from day one so Relyo can later support AWS, GCP, Azure, Firebase, Neon, Railway, Render, Netlify, Clerk, Auth0, WorkOS, Twilio, SendGrid, Postmark, Paddle, Lemon Squeezy, Shopify, OpenAI, Anthropic, Gemini, object storage, queues, cron, mobile stores, and future autonomous software platforms.

## North-star outcome

Relyo does not declare success because a build passed or an agent says a task is done.

A capability is complete only when Relyo can produce independent production evidence that the expected outcome works end to end.

**Whatever AI built, Relyo makes sure reality agrees.**
