# Relyo V2 — Fundraising Operating Package

> **STATUS: ACTIVE FUNDRAISING OPS PLAN**

## Rule

Fundraising starts when the product creates evidence. Do not raise primarily on ambition if a working proof loop can be shown first.

## Pre-seed trigger

Start a serious process when Relyo has most of:

- working Verify My Launch flow;
- signed Production Passport;
- 10–30 design partners;
- real failure/outcome data;
- first paid proofs;
- credible organic acquisition;
- one or more agency/builder pilots.

## Initial raise target

Base target:

> **$1M–$2M pre-seed**

Stretch only if traction supports it.

Use of funds:

- product/infra engineering;
- security/reliability engineering;
- growth/devrel;
- cloud/proof execution costs;
- legal/incorporation/IP;
- minimal design/ops.

## Core investor narrative

> Software creation is becoming abundant. Independent production trust is not. Relyo is building the proof layer that can sit between any software producer and the real world.

## Pitch deck structure

1. The shift — machine-built software volume is exploding.
2. The problem — production outcomes remain hard to trust.
3. The product — Verify My Launch + Production Passport.
4. The magic demo — connect app → discover → prove → Passport.
5. Why now — AI creation speed + verification gap.
6. Market — developer infrastructure + software assurance + platform usage.
7. Business model — launch proof, continuous proof, API, agency, enterprise.
8. Growth — free checks + Passport + agencies + builder embeds.
9. Moat — Proof Contracts + Runner + Verified Failure Graph + trust network.
10. Traction — real numbers only.
11. Competition — fragmented adjacent categories, neutral proof layer differentiation.
12. Team.
13. Raise + milestones.

## Process design

### Wave 0 — feedback

5–10 friendly operators/investors. Ask for critique, not money.

### Wave 1 — high-fit

10–20 highest-fit investors within a concentrated 2–3 week window.

### Wave 2 — broader

Expand only after deck/demo feedback is incorporated.

## Demo sequence

### Demo A — Verify My Launch

- connect app;
- map dependencies;
- show one material risk/unknown;
- execute proof;
- issue Passport.

### Demo B — external agent

- agent submits proof via API/MCP;
- Relyo returns evidence;
- agent fixes;
- Relyo re-verifies.

### Demo C — trust degradation

- break a contract;
- Passport degrades;
- recover/reverify;
- Passport restores.

## Fundraising milestones the round should buy

12–18 months target:

- strong initial stack coverage;
- 10k+ active verified apps or equivalent high-quality usage;
- meaningful recurring revenue;
- 3–10 builder/agency/platform distribution relationships;
- mature Verified Failure Graph;
- private runner/security foundation;
- repeatable paid acquisition/partner loop.

## Never do

- claim a guaranteed valuation;
- use fake ARR/run-rate;
- count free scans as customers;
- present LOIs as revenue;
- imply partnership without agreement;
- exaggerate builder failure statistics.
